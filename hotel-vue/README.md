# hotel-vue

Vue 3 + Vite версія каталогу готелю Hilton Київ (лабораторна робота №9).

Повний звіт, структура компонентів і пояснення `props`/`emits` у [головному README](../README.md).

## Команди

```
npm install
npm run dev
npm run build
```

Потрібна актуальна LTS-версія Node.js (перевірено на 24.22.1).
